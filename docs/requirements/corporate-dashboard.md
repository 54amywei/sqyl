# 对公业务全景 · 哈尔滨分行：需求基线（待确认）

> 根据用户提供的需求与设计说明整理。说明中的功能是设计意图，不自动代表业务口径、数据真实性、授权或生产要求。未逐项确认前，不得据此接入真实经营数据或公开发布。

## 目标与范围
移动端对公经营看板，供分行管理层、支行负责人和客户经理查看经营概况。说明提出 iOS Safari、Android Chrome、微信浏览器适配，兼顾 360px 窄屏和全面屏安全区。具体用户、决策场景、机构覆盖和首期范围待业务确认。

## 页面结构
- 全局：吸顶导航、存款/贷款/客户/报表中心四个主页面、数据日期、同步状态。
- 存款：开门红入口、余额/日均、实时存款横幅、结构卡、走势图、排名和下钻。
- 贷款：余额/日均、走势图、排名和下钻。
- 客户：客户汇总、有效/基础客户卡、目标进度、走势图、排名和下钻。
- 报表中心：专题战报、存款、客户和业务主题报表，明细抽屉。
- 开门红：核心指标及存款/客户/资产/结构战报子页。
- 通用交互：日期联动、指标切换、图表提示、排名排序、机构/人员维度切换、五级下钻、抽屉和横向滚动表格。

## 需求说明列出的功能清单
- 存款：对公存款余额、日均、实时余额、较昨日增量、当日新增、一般性存款、活期、结贷比、保证金。
- 贷款：对公贷款余额、日均。
- 客户：客户总数、有效客户占比、人均有效户、有效客户、基础客户、目标完成度。
- 对比期间：比上日、比上月、比上季、比上年。
- 维度：支行、经营单位、办公室、客户经理；下钻描述为全行→机构/部门→员工→客户→账户。
- 报表：说明文档列出的12个报表/专题入口；正式名称和字段需业务确认。
- 日期、15秒静默刷新、实时状态、排名、红金专题等行为均待确认。

## 待业务/数据负责人确认
- 各指标定义、公式、单位、期末/日均逻辑、对比基准、数据源字段和责任人。
