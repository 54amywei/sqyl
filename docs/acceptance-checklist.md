# 看板验收清单

## 业务
- [ ] 页面用户、用途、首期范围已确认。
- [ ] 指标定义、公式、单位、期间、维度、数据源和更新频率已核实。
- [ ] 日期/实时状态/异常状态与数据时效一致。
- [ ] 排名、目标进度、筛选、下钻和报表权限已确认。
- [ ] 数据对账基准和业务验收人明确；结论关联到提交或版本标签。

## 交互视觉
- [ ] 导航、日期、指标切换、图表提示、排序、下钻和抽屉行为符合确认规格。
- [ ] 目标手机/桌面宽度、全面屏安全区、横向表格和长文本可用。
- [ ] 空数据、加载、接口失败、无权限和过期数据状态已检查。
- [ ] 预览/截图对应本次提交。

## 技术安全
- [ ] 开发者审阅完整 diff，改动均属于对应 Issue。
- [ ] 按项目现有方式执行验证并如实记录结果。
- [ ] 没有密钥、客户/员工信息或未经批准经营数据进入仓库和预览。
- [ ] 权限由可信后端执行，而非仅前端隐藏。
- [ ] AI 生成代码经开发核实；AI review 不作为唯一批准。

## 发布
- [ ] 发布人、环境、版本、上线时段和回滚步骤明确。
- [ ] 生产发布记录关联 PR、提交和业务验收。
